## ✨ Veb-Portalning Asosiy Xususiyatlari

### 1. 🎨 Sharqona va Akademik Dizayn Tizimi
* **Ko‘zni charchatmaydigan sokin tongi rejim (Light Mode):** Nafis Alabaster foni, Qirollik Lojuvard Sapfiri (`#0e3a66`) va yumshoq antik bronza aksentlari bilan xalqaro **WCAG AAA** o‘qiluvchanlik standartiga moslangan.
* **Tungi rejim (Dark Mode):** Qadimiy ilmiy qo‘lyozma xazinalari va lojuvard Registon koshinlarini eslatuvchi sokin quyuq moviy-oltin palitra.
* **Akademik Tipografiya:** Dunyo yetakchi universitetlari va klassik nashrlariga xos **Marcellus**, **Cormorant Garamond** (sarlavhalar) va **Outfit** (matnlar) shriftlar majmuasi.

### 2. 🧭 Fanga Aloqador Jonli Animatsiyalar
* **Sharq Astrolyabiyasi halqalari:** Portret atrofida doimiy ravishda aylanuvchi 360° azimut koordinatalari va muqaddas geometriya naqshi.
* **Orbitadagi 4 ta ilmiy ramz:** Doimiy suzuvchi 📜 *Qo‘lyozma*, 🧭 *Astrolyabiya*, ✒️ *Xattotlik* va 🏛️ *Tasavvuf* nishonlari.
* **Ilmiy Manbalar Tasmiri (Meridian Ticker):** Doimiy aylanuvchi kompas va tadqiqot geografiyasi: *Buxoro (39°46′N) • Samarqand (39°39′N) • Toshkent (41°18′N) • XV–XX asr qo‘lyozmalari*.
* **Interaktiv Falakiyot To‘ri (Constellation Canvas):** Kursorni kuzatuvchi munajjimlik yulduzlari, 4 qirrali nur chaqnashi (✦) va yengil nur iplari.

## 🚀 Mahalliy Kompyuterda Ishga Tushirish

Loyihani o‘z kompyuteringizda ishga tushirish uchun quyidagi buyruqlarni ketma-ket bajaring:

```bash
# 1. Repozitoriyni klonlash
git clone https://github.com/Yashnarbek-Samiyev/Nargiza-Xidirova.git

# 2. Loyiha papkasiga o'tish
cd Nargiza-Xidirova

# 3. Istalgan lokal server orqali ishga tushirish (masalan, Python orqali):
python3 -m http.server 8080

# 4. Brauzerda ochish:
# http://localhost:8080/
```

Yoki **VS Code** muhitida **"Live Server"** kengaytmasi orqali `index.html` faylini ochib, bir bosishda ishga tushirishingiz mumkin.
